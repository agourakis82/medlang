# ⚠️ Repository Archived

This repository has been **archived** as of December 2025.

MedLang has been unified into the **Sounio Programming Language**.

## New Home

- **Repository**: [sounio-lang/sounio](https://github.com/sounio-lang/sounio)
- **Module**: `stdlib/medlang/`
- **Import**: `import sounio::medlang::*`

## Why Archive?

Sounio provides native epistemic computing (`Knowledge<T>`) which makes uncertainty 
propagation automatic — essential for pharmacometrics. MedLang is now a module 
within Sounio, not a separate project.

## Historical Reference

This repository remains available for historical reference but is no longer 
maintained. All active development happens in the Sounio repository.

See [README_ARCHIVE.md](README_ARCHIVE.md) for full details.
