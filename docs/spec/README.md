## 🔍 How to Use

1. **To implement the compiler**: Start with Grammar V1.0 and Core Specification
2. **To understand the language**: Read the grammar and relevant extension specifications
3. **To extend the language**: Consult existing specifications as reference

## 📝 Versions

Specifications are versioned. The current version is indicated in the filename (v0.1, v1.0, etc.).

## 🔄 Updates

As the language evolves, new specification versions are added. Old versions are kept for historical reference.
